# 身份生成器 - Identity Generator

- 一个可以批量生成随机姓名和生日的项目

## 使用说明
- JDK 8、17、21
- Maven

### 步骤
1. Clone this repository:
    ```bash
    git clone https://github.com/phosicX/IdentityGenerator.git
    ```
2. Navigate to the project directory:
    ```bash
    cd IdentityGenerator
    ```
3. Compile and run the project:
    - **Using Maven**:
        ```bash
        mvn compile exec:java
        ```
